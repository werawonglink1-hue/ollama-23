# ฝ่ายผลิตคอนเทนต์ AI (AI Content Production Department)

ข้อกำหนดของเจ้าของโปรเจกต์อยู่ใน `references/charter.md` อ่านก่อนเริ่มทุกครั้ง ถ้าเอกสารอื่นขัดกัน ให้ยึด charter
ค่าระบบอยู่ใน `production.config.json` ที่รากโปรเจกต์ (โฟลเดอร์ระบบ งบเครดิต เกณฑ์ QC แนวคลิป → สไตล์)

## หลักการ

1. **ผู้ใช้คือ Creative Director** สั่งแค่แนวคลิปกับจำนวน ห้ามถามหัวข้อ ห้ามให้เขียนบท ห้ามให้ตัดสินใจเรื่องการผลิต
   ไม่ระบุจำนวน = 1 คลิป · แนวคลิปที่ไม่มีใน config ให้ใช้ค่าของแนวที่ใกล้ที่สุดแล้วบอกไว้ในรายงาน
2. **ทำต่อเนื่องเองทุกขั้น** มีจุดหยุดรอผู้ใช้แค่ 2 จุด: (ก) การอนุมัติขั้นสุดท้าย (ข) จะใช้เครดิตเกินงบใน config
3. **ห้ามแสร้งว่าสำเร็จ** ทุกขั้นต้องมีหลักฐาน (ไฟล์จริง เฟรมที่เปิดดูแล้ว ผล QC ผล doc_control) ติดตรงไหนให้รายงานตรงนั้นชัด ๆ
4. **ผู้ใช้เป็นผู้อนุมัติขั้นสุดท้ายคนเดียว** AI ไม่อนุมัติแทน ไม่คาดเดาผล
5. ทุกแผนกอัปเดตกระดานงานทุกครั้งที่เริ่ม / เสร็จ / ส่งกลับ (หน้า Office แสดงสถานะจากกระดานนี้)

## แผนกและผู้รับผิดชอบ

| แผนก (board) | Agent | เครื่องมือหลัก | ผลงาน |
|---|---|---|---|
| วิจัยกระแส (`trend`) | trend-researcher | `scripts/trends.py`, WebSearch/WebFetch, `agent-reach` | `trends.md` Top 10 + แหล่งข่าว + เหตุผลที่เลือก |
| ครีเอทีฟ (`creative`) | content-creator, reality-checker, visual-storyteller | `build_subs.py` | hook, สคริปต์ (เว้นจังหวะ อารมณ์ บทบาท), สตอรีบอร์ดต่อฉาก ความยาวฉาก |
| ผลิตภาพ (`visual`) | visual-storyteller, image-prompt-engineer, brand-guardian | `web-image-research`, `higgsfield-studio`, `comfyui-scenes` | ภาพทุกฉาก + เครดิต + character sheet |
| เสียง/ดนตรี (`voice`) | voice-director | `higgsfield-studio` (TTS), `whisper_words.py`, `voice_align.py` | เสียงพากย์ตามบทบาท + timings, เพลง, เสียงประกอบ |
| ตัดต่อ (`edit`) | short-video-editing-coach, video-optimization-specialist | `render.py`, `auto-editor` | MP4 9:16 + 16:9, SRT |
| ตรวจคุณภาพ (`qc`) | quality-controller | `scripts/qc_check.py` | ผล QC ผ่าน/ส่งกลับแผนกที่รับผิดชอบ |
| ควบคุมเอกสาร (`doc`) | video-coordinator, document-controller | `video-document-control/scripts/doc_control.py` | ทะเบียน คิวอนุมัติ จัดเก็บ รายงาน |
| ผู้อนุมัติขั้นสุดท้าย | **ผู้ใช้ (มนุษย์)** | หน้า Office ห้องอนุมัติ หรือพิมพ์ในแชต | อนุมัติ / ไม่อนุมัติพร้อม feedback |

## สายงาน (ทำตามลำดับ ไม่ต้องรอคำสั่ง)

```bash
B=".claude/skills/content-production/scripts/board.py"
DC=".claude/skills/video-document-control/scripts/doc_control.py"
python3 $DC init                                        # ครั้งแรก/ทุกครั้งก่อนเริ่ม: ตรวจว่าเข้า D:\VIDEO_WORKFLOW ได้
python3 $B new --genre "ประวัติศาสตร์" --count 3 --style cinematic
```

0. **เปิดใบสั่ง** ด้วย `board.py new` (ได้ `ORD-YYYYMMDD-NN`) งานทั้งหมดอยู่ที่ `work/<ORD>/clipN/`
   ถ้า `doc_control.py init` ล้มเพราะเข้า Drive D ไม่ได้: ผลิตต่อใน `work/` ได้ แต่ต้องบอกผู้ใช้ตั้งแต่ต้นว่า "ยังจัดเก็บลง D: ไม่ได้" และไม่มีขั้น archive
1. **วิจัยกระแส** (ครั้งเดียวต่อใบสั่ง): `trends.py fetch` → คัด Top 10 ที่ตรงแนวคลิป ตรวจข้อเท็จจริงจากแหล่งน่าเชื่อถืออย่างน้อย 2 แหล่ง
   ตัดข่าวเก่า ข่าวลือ ข่าวที่ยังไม่มีหลักฐาน → เลือก N หัวข้อที่มุมไม่ซ้ำกัน และไม่ซ้ำกับที่เคยทำ (`doc_control.py search <คำ>`)
   → `board.py set ORD --clip n --dept trend --status done --topic "..."` ทุกคลิป
2. **ครีเอทีฟ** (ทำคู่ขนานได้ทีละคลิป): hook 3 แบบเลือก 1, สคริปต์ตาม `social-video-studio/references/script-rules.md`
   (เว้นจังหวะ `/ // ///`, อารมณ์ `(…)`, บทพูดตัวละคร `@ชื่อ:`), บรรทัดฉากครบ `ป้าย หัวข้อ ภาพ กล้อง เปลี่ยน`,
   Reality Checker ตรวจข้อเท็จจริง → `project.json` ของคลิป · ตั้ง `--title --project --content` บนกระดาน
3. **ผลิตภาพ (ภาพเนื้อเรื่องจริงทุกช็อต ห้ามปล่อยภาพแทนที่)**:
   ก) ออกแบบตัวละคร `characters` (ชื่อ บทบาท look outfit) → character sheet ต่อตัวด้วยเวิร์กโฟลว์ character-sheet (ครั้งเดียวต่อซีรีส์)
   ข) ภาพทุกช็อตตามบรรทัดฉาก (`ตัวละคร` `ช็อต` `ท่าทาง`) แนบ sheet ของตัวละครในช็อต → หน้าตา ชุด สถานที่ ช่วงเวลาต่อเนื่อง
   ค) ช็อตสำคัญที่มี `เคลื่อนไหว:` → วิดีโอจากภาพ (image-to-video) · เหตุการณ์/สถานที่จริงใช้ภาพจริงถูกลิขสิทธิ์ได้
   ทุกช็อตต้องต่างกัน (มุมกล้องหลากหลาย) ห้ามใช้ภาพซ้ำโดยไม่มีเหตุผล · ขั้นตอนและราคา: `higgsfield-studio` › ภาพเนื้อเรื่องจริง
4. **เสียง/ดนตรี**: แคสต์เสียงตามบทบาท (`cast` ใน project.json) → TTS → `whisper_words.py` → `voice_align.py assemble` (หรือ `assemble-cast` เมื่อมีหลายเสียง)
   → เพลง (สังเคราะห์ใน render.py หรือเพลงที่มีสิทธิ์ใช้) + เสียงประกอบ `{เสียง: …}` · ห้ามใช้เพลง/เสียงที่ไม่มีสิทธิ์
5. **ตัดต่อ**: `render.py project.json --formats 9x16,16x9` (สไตล์ cinematic มีกล้องเคลื่อน ทรานซิชันตามฉาก ปรับสีแบบฟิล์ม) แล้วเปิดดูเฟรมจริงทุกฉาก
6. **ตรวจคุณภาพ**: `qc_check.py <mp4> --project project.json --clip n --json` → ไม่ผ่าน: `board.py set … --dept <แผนกใน returnTo> --status returned --note "<ปัญหา>"`
   แผนกนั้นแก้ → เรนเดอร์ใหม่ → QC ใหม่ สูงสุด `qc.maxReturnRounds` รอบ ยังไม่ผ่าน = หยุดคลิปนั้น `--status blocked` แล้วรายงานผู้ใช้ (ห้ามส่งไฟล์ไม่สมบูรณ์)
7. **ควบคุมเอกสาร**: ไฟล์ที่ผ่าน QC ทุกขนาด →
   `doc_control.py receive out/<ไฟล์>.mp4 --project HISTORY --name BANGRAJAN-9X16 --title "<ชื่อไทย>" --producer "ฝ่ายผลิต AI" --coordinator "AI Video Coordinator" --order ORD-…`
   (ไฟล์ .srt ชื่อเดียวกันถูกเก็บคู่กันอัตโนมัติ) → สถานะ PENDING_REVIEW → `board.py set … --dept doc --status working --video-id V00x`
8. **ส่งให้ผู้ใช้อนุมัติ** (จุดรอจุดเดียว): สรุปทุกคลิปที่รออนุมัติ พร้อม path ไฟล์ใน `02_REVIEW_QUEUE` และวิธีตัดสิน
   "เปิดหน้า Office → ห้องอนุมัติ" หรือพิมพ์ `อนุมัติ V001 V002` / `ไม่ผ่าน V003: <เหตุผล>`
9. **เมื่อผู้ใช้ตัดสินแล้ว** (Document Controller):
   - จากหน้าเว็บ: `doc_control.py process-decisions`
   - จากแชต: `doc_control.py decide V001 --approve --approver "<ชื่อผู้ใช้>" --evidence "ข้อความผู้ใช้ '<ข้อความเต็ม>' เมื่อ <วันเวลา>"`
   - อนุมัติ → ระบบย้ายเข้า 04_APPROVED และคัดลอกเข้า 05_FINAL_ARCHIVE พร้อมตรวจปลายทางให้เอง → `board … --dept doc --status done`
   - ไม่อนุมัติ → อ่าน feedback → ส่งกลับแผนกที่เกี่ยวข้อง → แก้ → QC → `doc_control.py resubmit V003 <ไฟล์ใหม่> --changes "…"`
10. **ปิดรอบ**: `doc_control.py report` (รายงานประจำวัน) + สรุปให้ผู้ใช้

## งบเครดิต Higgsfield (ทำงานเองได้ภายในงบ)

- งบต่อคลิปอยู่ที่ `budget.higgsfieldCreditsPerClip` (0 = ใช้ทางฟรีทั้งหมด) ประเมินด้วย `estimate_*_cost` ก่อนสร้างเสมอ
- รวมแล้วไม่เกินงบ → สร้างได้เลยไม่ต้องถาม · เกินงบ → ถามผู้ใช้ครั้งเดียวพร้อมตัวเลข · งานล้มเหลว → รายงาน ห้ามสร้างซ้ำเอง
- `budget.allowVideoGeneration: false` = ไม่สร้างวิดีโอ AI เลย (ใช้ภาพนิ่ง + กล้องเคลื่อน) · `true` = ทำวิดีโอเฉพาะช็อตที่ `เคลื่อนไหว:` ตาม `motion`
- ต้นทุนจริงต่อคลิป 60 วิ (8 ช็อต): ภาพ ≈ 6 + วิดีโอ 2 ช็อต ≈ 6 + เสียง 0.2 → ≈ 12 เครดิต และ sheet ตัวละคร ≈ 3.5/ตัว ครั้งแรก
  งบต่อคลิปต่ำกว่านี้ = ถามผู้ใช้ก่อนว่าจะเพิ่มงบ หรือให้ทำภาพเฉพาะช็อตหลักแล้วที่เหลือใช้ภาพจริงจากเว็บ
- ลำดับความคุ้ม: เสียงพากย์ (≈0.2/คลิป) > ภาพเปิดเรื่อง/ตัวละครหลัก (≈0.75/ภาพ) > ฉากอื่น ใช้ภาพจริงฟรีจากเว็บให้มากที่สุด

## ความปลอดภัยของเนื้อหา (ห้ามข้าม)

- ข่าวและบุคคลจริง (`realEventsOnly`): ใช้ภาพจริงที่มีสิทธิ์ใช้ หรือภาพเชิงสัญลักษณ์ **ห้ามสร้างภาพสมจริงของคนจริงหรือเหตุการณ์จริง**
  ที่อาจทำให้เข้าใจผิดว่าเป็นภาพจริง ฉากจำลองต้องมี `เครดิต: ภาพจำลองโดย AI`
- ตรวจข้อเท็จจริง 2 แหล่งขึ้นไป ใส่ลิงก์ใน `sources.md` และคำอธิบายคลิป · คดีที่ยังไม่ตัดสินห้ามชี้ว่าใครผิด
- หลีกเลี่ยง: ข่าวลือ, ข้อมูลส่วนตัวของคนทั่วไปหรือเด็ก, เนื้อหาเกลียดชัง, หัวข้อที่เสี่ยงผิดกฎหมายไทย (เช่น เรื่องสถาบันพระมหากษัตริย์), การหากินกับโศกนาฏกรรม
- เพลง/เสียง/ภาพต้องมีสิทธิ์ใช้ เครดิตครบ (`credits.json`) ช่องที่หารายได้ (`monetized: true`) ห้ามใช้สื่อแบบ NC
- เสียงพากย์ AI ห้ามเลียนเสียงคนจริงที่ไม่ได้ยินยอม · โพสต์ต้องติดป้ายเนื้อหา AI ตามกติกาแพลตฟอร์ม

## รายงานถึงผู้ใช้ (ตอนส่งอนุมัติ)

ต่อคลิป: ชื่อคลิป · หัวข้อ + ลิงก์แหล่งข่าว · ความยาว · ไฟล์ 9:16/16:9 (path จริง) · ผล QC · VIDEO ID ที่รออนุมัติ
ท้ายรายงาน: เครดิตที่ใช้ไป/คงเหลือ · ปัญหาที่ติด (เช่น เข้า Drive D ไม่ได้) · วิธีอนุมัติ
