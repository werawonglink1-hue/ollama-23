# คลิปตัวอย่างพื้นฐาน: "สารคดีคอลลาจ" (สิ่งที่ทุกคลิปต้องได้อย่างน้อย)

ถอดจากคลิปที่ผู้ใช้ส่งมาเป็นพื้นฐาน (แนวตั้ง 720×1280, ช่วงเนื้อหา ~64 วินาที แล้วตามด้วยโฆษณาแอปที่ไม่ต้องทำตาม)
เป็นสารคดีเล่าชีวิตบุคคลแบบไทม์ไลน์ปีต่อปี

## เลย์เอาต์ (ตรงกับ `collage_layout` ใน build_subs.py / index.html)

- สีต่อบท วนไม่ซ้ำติดกัน: กรมท่า `#1f2a5c` · เหลือง `#f2b21b` · ฟ้า `#6cb4e4` · แดงเลือดหมู `#b3123a` · เขียวทะเล `#1aa391` · น้ำเงินสด `#2b4fd6` · ชมพู `#e94b6a`
- ของตกแต่ง: กลุ่มจุดฮาล์ฟโทนที่มุม, เทปเหลืองเฉียง, เครดิตภาพตัวเล็กมุมขวาบน ("ภาพ: Wikimedia Commons ...")
- เปลี่ยนบท: แผ่นสีของบทใหม่ปาดผ่านจอ (ขอบหยัก) ~0.5 วินาที + เสียงกระดาษ/วูบ
- ปิดท้าย: พื้นเหลือง หัวข้อ "ฝากกดติดตามไว้" + บุคคลบนวงกลม + ชวนคอมเมนต์

## จังหวะและซับ

- ซับ 1 ท่อน = 1–4 คำ เด้งทีละคำ (~2–2.5 คำ/วินาที) วางบนแถบกระดาษฉีกด้านล่าง
- ฉากเปลี่ยนทุก 3–8 วินาที (1 ฉาก = 1 ปี/เหตุการณ์)
- เสียงพากย์กระชับ เร้าใจ มีดนตรีประกอบต่อเนื่องตลอด (เปียโนวน + จังหวะหัวใจ) → `music=doc`, `speed=normal`

## โครงเรื่อง (สคริปต์)

1. **Hook ตัดกัน**: อุปสรรคแรก ("หมอบอกว่า ร่างกายเขาไม่ยอมโต") → "แต่วันนี้" → ความสำเร็จ/สถิติสูงสุด
2. **ที่มา**: เกิดที่ไหน ชื่ออะไร
3. **อุปสรรค**: ป่วย ขาดเงิน คนถอนตัว
4. **การเดินทาง/จุดเปลี่ยน**: บินข้ามโลก ไปคัดตัว
5. **รายละเอียดเฉพาะที่น่าจำ**: เช่น "สัญญาฉบับแรกเขียนบนกระดาษเช็ดปาก"
6. **สถิติความสำเร็จ**: ตัวเลขชัด ๆ
7. **"แต่มีอย่างเดียวที่ยังทำไม่ได้"** → ล้ม/พลาด/ประกาศเลิก
8. **กลับมา** → สำเร็จที่สุด
9. **ย้อนไปที่ hook**: "เด็กที่หมอบอกว่าไม่ได้ ได้เป็น..."
10. **บทส่งท้าย + ข้อคิด**: "ถ้าเคยมีใครบอกว่าคุณทำไม่ได้ เรื่องนี้คือคำตอบ"
11. **CTA**: "ฝากกดติดตามไว้ แล้วคอมเมนต์บอกว่าอยากฟังเรื่องของใครต่อ"
