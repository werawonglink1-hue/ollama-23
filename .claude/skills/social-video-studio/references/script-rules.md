# กติกาสคริปต์พูด

## รูปแบบไฟล์สคริปต์ (ใช้ทั้งเว็บและ `build_subs.py`)

```
[ฉาก: ห้องตรวจโรงพยาบาล ภาพเอกซเรย์เข่า | ป้าย: 2015 | หัวข้อ: เข่าพัง | โทน: ขาวดำ]
(ช้าลง) ปี *2015* // เข่า พัง // หมอ บอก ว่า / *ห้าม วิ่ง* / ตลอด ชีวิต ///
{เสียง: ลมพัดเบา ๆ}
```

| เครื่องหมาย | ความหมาย | ในเสียง | ในซับ |
|---|---|---|---|
| `/` | เว้นสั้น ~0.35 วิ | หายใจ | ตัดท่อนซับ |
| `//` | เว้นกลาง ~0.8 วิ | ให้คนดูคิดตาม | ตัดท่อน + ซับหายไปช่วงเว้น |
| `///` | เว้นยาว ~1.4 วิ | ก่อน/หลังจุดพีค เปลี่ยนอารมณ์ | ตัดท่อน + จอว่างนิดหนึ่ง |
| `*คำ*` | คำสำคัญ | ลงน้ำหนัก | สีไฮไลต์ |
| เว้นวรรคระหว่างคำ | ขอบเขตคำ | (ระบบลบช่องว่างก่อนส่งให้เสียงอ่าน) | ซับคำต่อคำเด้งทีละคำตรงช่องว่าง |
| `(อารมณ์)` | (กระซิบ) (ยิ้ม) (ตื่นเต้น) (ช้าลง) (เศร้า) (ลุ้น) (ขำ) | ปรับความเร็ว/ระดับเสียง | ไม่แสดง |
| `{เสียง: ...}` | เสียงประกอบ ณ จุดนั้น | | ไม่แสดง |
| `[ฉาก: ... \| ป้าย: \| หัวข้อ: \| ภาพ: \| โทน: \| สี: \| กล้อง: \| เปลี่ยน: \| เครดิต:]` | เปลี่ยนภาพ + ข้อมูลบนจอ + กล้อง/ทรานซิชัน (ดู `styles.md`) | | ป้าย/หัวข้อ/เครดิตแสดงบนการ์ด |
| `"..."` | เสียงตัวละครแทรก (ผู้บรรยายเลียนเสียง) | เปลี่ยนน้ำเสียง | แสดงพร้อมเครื่องหมายคำพูด |
| `@ชื่อ: ...` (ต้นบรรทัด) | บทพูดของตัวละคร พากย์ด้วยเสียงของตัวละครนั้น (แคสต์ใน `cast` ของ project.json) | เสียงต่างคน อารมณ์ตามบท | แสดงเฉพาะข้อความ |

ความเร็ว (`speed`) ปรับทั้งความเร็วอ่านและความยาวช่วงเว้น: `slow` เว้นเต็ม (ละมุน) · `normal` เว้น 75% (สารคดี) · `fast` เว้น 55%

## 1) สไตล์สารคดีเล่าชีวิต (`doc`, ค่าเริ่มต้น): ดู `baseline.md`

- 1 ฉาก = 1 ปี/เหตุการณ์ ทุกฉากใส่ `ป้าย:` (ปีหรือ "อายุ 13") และ `หัวข้อ:` 2–4 คำ
- **เว้นวรรคระหว่างคำทุกคำ** ในวลี เช่น `หมอ บอก ว่า / ร่างกาย เขา ไม่ ยอม โต` เพื่อให้ซับเด้งคำต่อคำตรงคำ
- วลีละ 1–4 คำ (≤ 14 ตัวอักษรฐาน) ใช้ `//` ระหว่างประโยค ใช้ `///` ก่อนจุดพลิกและหลังประโยคพีค
- ตัวเลขต้องจริง: ใช้ไทม์ไลน์/ข้อเท็จจริงที่ผู้ใช้ให้ ถ้าไม่มีและไม่แน่ใจ ห้ามแต่ง
- โครง 11 จังหวะ: hook ตัดกัน → ที่มา → อุปสรรค → จุดเปลี่ยน → รายละเอียดน่าจำ → สถิติ → "แต่มีอย่างเดียว..." → ล้ม → กลับมา → ย้อน hook → ข้อคิด + CTA
- ตัวอย่าง: `templates/sample-doc.txt`

### ข้อมูลไทม์ไลน์ที่รับจากผู้ใช้ (ช่องในเว็บ)

```
ปี | หัวข้อสั้น | เล่าเหตุการณ์
2008 | เริ่มจากศูนย์ | วิ่งเท้าเปล่า ไปโรงเรียน วันละ 10 กิโล
2015 | เข่าพัง | หมอบอกว่า ห้ามวิ่ง อีกตลอดชีวิต
```

ทำหลายคลิปจากไทม์ไลน์เดียว: คลิป 1 = เรื่องเต็มฉบับย่อ (ปี + หัวข้อ) · คลิป 2…N = แบ่งไทม์ไลน์เป็นช่วง เล่าละเอียด แต่ละคลิปจบด้วย "ตอนหน้า" ของช่วงถัดไป คลิปสุดท้ายจบด้วยข้อคิด + "ฝากกดติดตามไว้ แล้วคอมเมนต์บอกว่าอยากฟังเรื่องของใครต่อ"

## 2) สไตล์เล่าเรื่องละมุน (`lamun` / `mystery` / `funny`)

ถอดจากคลิปเล่าเรื่อง "โลกที่ปลาว่ายบนฟ้า" (แนวตั้ง 105 วินาที):
- เปิดด้วย **ชวนจินตนาการ**: "ลองนึกภาพว่า / โลกนี้ / ..." พูดกับคนดูด้วย **"คุณ"**
- **วลีสั้นมาก** 4–14 ตัวอักษร ค้างจอ ~1–2 วินาที
- กฎของโลก → ชีวิตประจำวันที่อบอุ่น → **กฎข้อเดียว / ข้อห้าม** → ค่ำคืนเงียบ จังหวะช้าลง → จุดพีค → คำถามค้างใจ
- ปิดด้วย **ตอนหน้า + ชวนคอมเมนต์**
- รายละเอียดเล็ก ๆ ทำให้โลกดูจริง ("ห้าทุ่มห้าสิบเก้า", "ตีห้า")
- ตัวอย่าง: `templates/sample-lamun.txt`

มุมเล่าเมื่อทำหลายคลิป: 1) ปฐมบท 2) มุมตัวละครรอง 3) ความลับ 4) คืนที่เปลี่ยนทุกอย่าง 5) ตอนจบอบอุ่น

## 3) ครูหน่อง (`kru-nong`) และ มานะ (`mana`)

- ครูหน่อง: "สวัสดีค่ะ / เด็ก ๆ จ๋า //" → กาลครั้งหนึ่ง → ปัญหา → "เด็ก ๆ ลองทายสิคะ //" (เว้นให้ตอบ) → สำเร็จ → "นิทานเรื่องนี้ / สอนให้รู้ว่า //" → ชวนคอมเมนต์
- มานะ: ประโยคสั้นซ้ำโครงแบบแบบเรียนยุคเก่า "นี่คือ*มานะ* // มานะอยู่ที่... // มานะชอบ... / น้องแก้วก็ชอบ..." ปิดด้วยคำพูดของแม่/ครู

## ให้ฟังละมุนที่สุด (ทุกสไตล์)

- ไม่ตะโกน ไม่ใช้ "!!!" ใช้คำลงท้ายนุ่ม "นะ", "เลย", "ค่อย ๆ"
- ใส่ `//` หลังประโยคที่อยากให้คนดูรู้สึก ใส่ `///` ก่อนประโยคพีค
- อย่าให้ 3 ท่อนติดกันยาวเท่ากัน สลับสั้น/ยาวให้เป็นจังหวะ

## บทพูดหลายตัวละคร (พากย์ตามบทบาท)

```
[ฉาก: บ้านไม้ริมโขง คืนฝนตก | กล้อง: ดันเข้า]
คืนนั้น / ฝนตกหนัก //
@แม่: (เศร้า) ลูกจ๋า / กลับบ้านเถอะนะ //
@ต้นกล้า: ผมจะวิ่งต่อครับแม่ ///
แล้วเขาก็วิ่ง / ทุกเช้า //
```

- บรรทัดที่ไม่มี `@` คือผู้บรรยาย · ชื่อหลัง `@` ต้องตรงกับคีย์ใน `cast` เช่น `"cast": {"ผู้บรรยาย": {...}, "แม่": {"voice_id": "...", "instruction": "หญิงวัย 45 อ่อนโยน ห่วงใย"}}`
- `voice_align.py prepare --cast project.json` แบ่งเป็นคำขอ TTS ทีละช่วงผู้พูด → `whisper_words.py` ทุกไฟล์ → `voice_align.py assemble-cast` ต่อเสียงตามลำดับพร้อมเว้นจังหวะ
- เปลี่ยนผู้พูดจะเว้นอย่างน้อย 0.25 วิ ใส่ `//` ท้ายบทพูดเพื่อให้คนดูซึมกับอารมณ์ก่อนเปลี่ยนเสียง
- เว็บตัดต่อพรีวิวด้วยเสียงอ่านของเบราว์เซอร์ที่ปรับระดับเสียงต่างกันต่อตัวละคร
