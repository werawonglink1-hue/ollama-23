# สตูดิโอคลิปเล่าเรื่อง (เว็บตัดต่อวิดีโอสำหรับโซเชียล)

เว็บหน้าเดียว `index.html` เปิดได้ทันทีใน Chrome / Edge (ดับเบิลคลิกไฟล์ หรือ `python3 -m http.server` แล้วเข้า `http://localhost:8000/video-studio-web/`)

## ใช้งาน

1. กรอก **เรื่อง/หัวข้อ** และ **ไทม์ไลน์** (บรรทัดละ `ปี | หัวข้อสั้น | เหตุการณ์`) ตัวละคร ฉาก ชื่อซีรีส์ ข้อคิด
2. เลือกจากดรอปดาวน์: **จำนวนคลิป 1–5**, ความยาว, **สไตล์ภาพ**, **สไตล์การเล่า**, **ขนาดคลิป** (แนวตั้ง 9:16 / แนวนอน 16:9 / ทั้งสอง / 1:1 / 4:5), รูปแบบซับ, ดนตรี, ความเร็ว, เสียงประกอบ, กรอบ+แถบหัว
3. กด **สร้างคลิป** ได้การ์ดคลิปละใบ แต่ละใบมี:
   - ▶ พรีวิว (ใช้เสียงอ่านภาษาไทยของเบราว์เซอร์ ซับเดินตามเสียงจริง)
   - กล่องสคริปต์แก้ได้ทันที (`/ // ///` เว้นจังหวะ, `*คำ*` ไฮไลต์, `[ฉาก: ... | ป้าย: | หัวข้อ: | ภาพ: วงกลม]`)
   - 🖼 ใส่รูป/วิดีโอฉาก (เลือกหลายไฟล์ ใส่ตามลำดับฉาก)
   - 🎙 อัดเสียงพากย์ + ซิงก์ซับ (อ่านตามบทที่ขึ้นจอ กด Space ทุกครั้งที่เริ่มวลีใหม่) หรือ 📁 ใช้ไฟล์เสียง + ⏱ แตะเพื่อซิงก์
   - ⬇ วิดีโอ (บันทึกแบบเรียลไทม์เป็น MP4/WebM พร้อมเพลง เสียงประกอบ และเสียงพากย์ที่อัด/อัปโหลด) · ⬇ ซับ SRT
   - สตอรีบอร์ด + prompt ภาพ AI ต่อฉาก (ปุ่มคัดลอก)
4. ⬇ **project.json** แล้วเรนเดอร์คุณภาพสูงด้วย `python3 .claude/skills/social-video-studio/scripts/render.py project.json --out out/`
   (วางไฟล์รูป/เสียงที่ชื่อระบุใน project.json ไว้โฟลเดอร์เดียวกัน)

## ค่าเริ่มต้น = แบบคลิปตัวอย่างพื้นฐาน

สไตล์ภาพ **สารคดีคอลลาจ กระดาษฉีก** + ผู้เล่า **สารคดีเล่าชีวิต** + ซับ **คำต่อคำ** + เพลง **สารคดีเร้าใจ** + กรอบมีแถบหัว 3 บรรทัด
รายละเอียดอยู่ที่ `.claude/skills/social-video-studio/references/baseline.md`

สไตล์อื่นในดรอปดาวน์: 3D พาสเทลละมุน, ดินน้ำมันจัดจ้าน, สีน้ำ, อนิเมะยามเย็น, กระดาษตัด, นีออนกลางคืน, ฟิล์มเก่า
ผู้เล่า: เล่าเรื่องละมุน, ครูหน่อง (ครูใจดีเล่านิทาน), มานะ (แบบเรียนไทยคลาสสิก), ลึกลับนุ่ม ๆ, ขำอบอุ่น

## ผู้เขียนสคริปต์

- **เทมเพลตในเครื่อง**: ฟรี ไม่ต้องต่อเน็ต สร้างจากไทม์ไลน์/ข้อมูลที่กรอก
- **Claude API**: ใส่ API key ของคุณ เขียนสคริปต์ใหม่ทุกครั้งตามกติกาเดียวกัน (คีย์ใช้เรียก API จากเบราว์เซอร์โดยตรง ไม่ถูกบันทึก)

## ข้อจำกัด

- เสียงอ่านอัตโนมัติของเบราว์เซอร์ใช้พรีวิวได้ แต่บันทึกลงไฟล์วิดีโอไม่ได้ ถ้าต้องการเสียงพูดในไฟล์ให้อัดเสียงเอง (🎙) หรือใช้ไฟล์เสียง
- การบันทึกวิดีโอทำแบบเรียลไทม์ (คลิป 60 วินาทีใช้เวลา ~60 วินาที) ต้องเปิดแท็บค้างไว้
- ใช้ภาพที่มีสิทธิ์ใช้งาน และใส่ `เครดิต:` ในบรรทัดฉาก

## เวอร์ชันที่เผยแพร่บน claude.ai

ไฟล์ `index.html` เดียวกันตรวจได้เองว่ากำลังเปิดบน claude.ai หรือเปิดจากเครื่อง:

| | เปิดจากไฟล์ในเครื่อง | เปิดบน claude.ai |
|---|---|---|
| เขียนสคริปต์ด้วย Claude | ใส่ Anthropic API key | ใช้บัญชี Claude ของผู้เปิด (ถามอนุญาตครั้งแรก) ไม่ต้องใส่คีย์ |
| บันทึกไฟล์ (วิดีโอ, ซับ, project.json) | ดาวน์โหลดทันที | ผ่านหน้าต่างยืนยัน ซับบันทึกเป็น `.srt.txt` (ลบ `.txt` ก่อนอัปโหลด) |
| เสียงอ่านพรีวิว | เสียงไทยของเบราว์เซอร์ | เสียงไทยของเบราว์เซอร์ ถ้าไม่มีใช้เสียงอ่านของ Claude |
| อัดเสียงพากย์ด้วยไมค์ (🎙) | ได้ | ไม่ได้ (หน้าเว็บบน claude.ai ใช้ไมค์ไม่ได้) ใช้ 📁 ไฟล์เสียง + ⏱ แตะเพื่อซิงก์แทน |

ไฟล์ที่ใช้เผยแพร่คือ `index.html` ที่ตัดแท็ก `<!doctype>`, `<html>`, `<head>`, `<body>` และ meta charset/viewport ออก (claude.ai ใส่โครงหน้าเอง)
